# Troubleshooting
## Narration cuts off
Confirm actual audio. Create narration as a separate complete track and synchronize it in the editor.
## Repeated or frozen frames
Reduce action complexity; split the shot and regenerate only the failed portion.
## Character changes appearance
Use stable IDs, consistent wardrobe and supported image references.
## Audio fix changes the video
Keep the LOCKED video and replace only its audio layer.
## Total film is too long
Recalculate narration, transitions and shot timing before generating more clips.
