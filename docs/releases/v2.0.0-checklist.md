## Historical proposed GitHub release notes — V2.0.0

> This was the proposed release-note text prepared before the official [v2.0.0 release](https://github.com/montadhahri/universal-ai-film-director/releases/tag/v2.0.0). It is preserved as historical preflight context, not an instruction to publish again. No further film publication or provider execution is authorized.

**Universal AI Film Director V2.0.0** reorganizes the original filmmaking direction skill into seven portable Agent Skills: one Director and six specialists (Storytelling, Visual Direction, Cinematography, Video Production, Sound Direction and Continuity QA).

### Highlights

- **Modular skills and workflow:** a user-guided nine-stage creative process with screenplay, Visual Bible and storyboard approvals; scoped revisions and clear boundaries on provider use.
- **Planning and validation:** deterministic, provider-free production-pipeline contracts, checkpoint serialization and recovery checks, plus specialist regression and creative-benchmark evidence.
- **Installability:** seven skills available from the public GitHub repository via Skills CLI. Successful CI installation tests do not demonstrate independent live invocation in two separate hosts.
- **The Last Light:** text documentation and five ChatGPT-generated reference keyframes from a 30-second, human-guided film experiment. The Google Flow / Veo 3.1 Fast V9 MP4 is **not bundled with V2.0.0**. Past Git history may still contain it. This is not proof of autonomous seven-agent production or final film approval.

### Important limitations and licensing

- **No autonomous video-generation promise:** this version provides creative direction, prompts, state/approval contracts and offline checks; it does not ship an authorized autonomous seven-agent production service or bundled provider credentials.
- **Code and skills:** MIT-licensed. **The Last Light's five PNGs:** included under [separate, non-MIT media terms](../case-studies/the-last-light/MEDIA-TERMS.md). **The V9 MP4 is excluded from V2.0.0 source archives**, though historical Git access is not eliminated. No new video distribution or unrestricted image-reuse rights are granted.
- **Remaining verification:** complete historical binary/privacy clearance was not achieved (the owner accepted the historical ZIP uncertainty); current five-keyframe QA and any applicable third-party image rights remain only partially evidenced. Google Flow account/date-specific terms remain unresolved **for the historical film**; the V9 MP4 is not in the V2 release tree. Source-history accessibility and all remaining caveats remain disclosed.
- **Production GO remains HOLD:** release of skills would not authorize paid provider jobs, connected accounts or further film publication.
