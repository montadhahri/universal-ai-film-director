## Scope and intended users

v1.0.0 is a **portable instruction-based filmmaking Agent Skill** for compatible
AI agents. It guides discovery, script development, visual design, shot planning,
sound planning, generator-oriented shot prompts, review and localized repair.
It is **not** an autonomous film renderer or a Google Flow/ElevenLabs integration.

## Included capabilities

- Exactly one focused discovery question per turn, with a checkpoint-aware
  resumption path for already provided stories, constraints and approvals.
- Explicit screenplay, visual-bible and storyboard user approval gates.
- Versioned Project Bible and decision provenance, shot lifecycle
  `DRAFT` / `PROPOSED` / `APPROVED` / `LOCKED` / `NEEDS_FIX`.
- Cinematography, camera, blocking, lighting and duration planning.
- Separate video/image, audio and editing guidance, with narration and
  intentional-silence timeline checks.
- Google Flow/Veo-aware guidance and provider capability verification:
  model capabilities are marked UNVERIFIED until documented or observed.
- Evidence-based QA, defect reports, locked-shot preservation and narrow
  repair proposals. No claim to have inspected or generated unavailable media.
- An isolated, runtime-only **34-file** installable skill package,
  mirrored byte-for-byte from the canonical root source.
- Node.js built-in regression, behavior, package and private pre-production
  validation, plus an actual Skills CLI **local-folder** installation smoke test.

## Installation

Authenticated repository access is needed because the project remains PRIVATE.
Use the isolated skill subdirectory rather than the repository root:

```bash
npx skills add https://github.com/montadhahri/universal-ai-film-director/tree/main/skills/universal-ai-film-director -g
```

Confirm discovery in the chosen agent. A real **local-folder** CLI install passed
CI. **Direct authenticated installation from the private remote GitHub URL has
not been independently verified**; do not interpret this command as a passed
remote-install test. Manual loading remains an option.

## Known limitations and explicit exclusions

- No integrated Google Flow/ElevenLabs browser/API tool or built-in video
  model. Generating cinematic clips requires an authorized external tool.
- No guarantee of coherent, photorealistic visuals, face consistency, sound
  quality, real-time playback, autonomous credit consumption or final MP4.
- The flagship repository example is synthetic; the rejected programmatic
  marketing demo PR #22 was closed without merge.
- No authenticated private remote installation acceptance.
- Other supported agent environments are untested unless explicitly evidenced.
- An installed Agent Skill is **not** automatically a multi-agent system.
- Real media QA, generation and end-to-end movie acceptance remain incomplete.

## Upgrade and compatibility

No v2 modular-specialist architecture is included in v1.0.0. The proposed
v2 roadmap lives in a separate PR. Existing manual skill loading and isolated
package use remain the supported baseline. Runtime requires no Python.
Node.js is used for the optional Skills CLI installer and repository tests.
