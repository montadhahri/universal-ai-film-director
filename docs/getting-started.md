# Getting started
1. Load `SKILL.md`.
2. Ask: "Help me create a 10-minute animated film using Google Flow. Ask one question at a time."
3. Answer the director's questions.
4. Approve script, visual bible and storyboard.
5. Choose the actual generator/model and verify its limitations.
6. Generate and review one shot at a time.
7. Save the Project Bible for handoffs.
8. Assemble approved clips and sound in an editor; complete final QC.
