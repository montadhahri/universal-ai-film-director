# V2.0.0 — release candidate notes (DRAFT)

**Status:** Prepared, not published. Repository remains private pending owner authorization and public-exposure checks.

## Highlights

- Seven portable Agent Skills: one Director and six specialist skills for storytelling, visual direction, cinematography, video production, sound direction and continuity QA.
- Explicit screenplay, visual and storyboard approval gates, scoped revision controls and provider authorization boundaries.
- Deterministic, provider-neutral production pipeline validation, checkpoint serialization and fresh-process recovery.
- Offline regression suites, quality benchmark documentation and local Skills CLI installation smoke tests.
- *The Last Light*: 30-second, five-shot **human-guided** V9 film case study using ChatGPT-generated keyframes, owner-operated Google Flow / Veo 3.1 Fast shots and local assembly. Not evidence of autonomous seven-agent production.

## Installation after publication

```bash
npx skills add montadhahri/universal-ai-film-director --skill universal-ai-film-director
```

For all seven: `npx skills add montadhahri/universal-ai-film-director --skill '*'`.

These public remote installation commands **must be tested from an unauthenticated environment after visibility changes**. Passing private/local installation CI does not establish public install success.

## Known limitations

- The skills guide filmmaking and prepare provider prompts; they do not independently operate or pay for video-generation services.
- Autonomous seven-agent end-to-end film production has not been independently demonstrated.
- *The Last Light* is a screening candidate, not a final film-publication approval or definitive media QA pass.
- Historical credential-pattern scanning passed, but does not prove absence of personal information in media, Git history or binary files.
- AI media provider terms were reviewed at a general level; rights/privacy and any service-specific conditions still require the release decision.
