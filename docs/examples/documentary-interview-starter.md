# Documentary interview starter — planning-only reusable example

**Purpose:** illustrate a non-fiction, interview-led workflow without claiming a real interview, consent, recording or licensed media. This is a **synthetic planning fixture**, not a completed film or independent agent execution.

**Project:** `COMMUNITY-GARDEN-DOC-01` · 30-second documentary concept · 16:9 · interview language TBD · no-cost planning.

**Premise:** a fictional community gardener explains how neighbors transformed an unused courtyard. No real person, organization, address, recording, likeness or media asset is supplied.

## 1. Director and Project Bible

Start with the [Project Bible template](../../skills/universal-ai-film-director/assets/project-bible-template.md). Set screenplay/interview outline, visual bible and storyboard gates to **PROPOSED**, with approval evidence **UNKNOWN**. Record the following as unresolved before real-world filming:

- Interviewee identity, informed consent, permitted use of voice/likeness and exact quotations
- Location access, filming permission, bystander privacy and release/retention terms
- Archival image/music ownership, licenses and attribution
- Accessibility: planned captions, readable titles and an audio-described equivalent where needed
- Production GO = `false`; provider job allowed = `false`; publication allowed = `false`

The canonical machine contract is [Project Bible schema](../../contracts/project-bible.schema.json); this Markdown is **not** a schema-valid JSON project export.

## 3. Seven-skill handoff checklist

1. **Director:** capture factual uncertainty, consent, versioned gates and next safe action.
2. **Storytelling:** propose interview questions and structure; never invent a real interviewee's words.
3. **Visual direction:** propose palette, respectful framing, location/identity continuity and consent constraints.
4. **Cinematography:** reconcile the four-shot timing and propose coverage, angles and axis.
5. **Sound direction:** use the [audio timeline template](../../skills/film-sound-direction/assets/audio-timeline-template.md); label all recordings and licenses **NOT_OBTAINED**.
6. **Video production:** use the [shot packet template](../../skills/film-video-production/assets/shot-packet-template.md) with provider `UNVERIFIED`, execution `PLAN_ONLY` and no media jobs.
7. **Continuity QA:** use the [shot review template](../../skills/film-continuity-qa/assets/shot-review-template.md) to flag consent, geography, interview-to-B-roll synchronization and missing source evidence.

Use the [checkpoint template](../../skills/universal-ai-film-director/assets/checkpoint-template.md) for the next session. Do not mark it saved unless persistence is verified.
