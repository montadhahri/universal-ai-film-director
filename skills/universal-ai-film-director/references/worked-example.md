# Worked Director scenario — the last spark (illustrative, not a completed film)

**User premise:** "The sun has disappeared. A little girl carries the last spark across an abandoned city and releases it from an ancient tower, creating a sunrise." **Requested length:** 30 seconds; language: English voice-over. These are example **supplied** constraints, not invented approvals or a reference to an actual generated film.

## Director response sequence

1. First recover known facts: protagonist (little girl), obstacle (abandoned dark city), object (spark), climax (tower and release), length (30s), narration language (English). Don't ask again about the plot or length.
2. If no essential constraint remains, propose a 3-act screenplay with 4–6 short visual beats and a brief voice-over. Mark **SCREENPLAY-V1 PROPOSED**. Ask for explicit approval of this exact version.
3. Only after screenplay approval, propose a Visual Bible: persistent character ID, cloak/hairstyle, city architecture, spark color, tower geography and pre-sunrise lighting. Mark **VISUAL-BIBLE-V1 PROPOSED**; seek separate approval.
4. Only after visual-bible approval, propose a contiguous 30s storyboard with stable shot IDs and exact start/end seconds. Seek separate storyboard approval.
5. Coordinate sound cues and generator packets; require separate external-operation authorization. If no video tool is available, say the project is **PLANNED** and output prompts, not a generated movie.
6. On defect "the narration stops at 18s", preserve approved pictures; propose a scoped audio fix, request/inspect actual media as needed, and verify a replacement export only when it exists.

## Example single-question response (after premise)

> This can work as a 30-second film with a quiet, emotional payoff. Would you prefer a gentle fairy-tale style or a darker realistic style?

If the user has already chosen the style, do **not** ask this again.

## Failure checks

- Do not silently treat "looks good" as approval of three different artifacts.
- Do not change locked shots to fit a new narration take.
- Do not claim a 30-second MP4 exists merely because the timeline totals 30 seconds.
- Do not assume the agent can delegate automatically to another skill.
