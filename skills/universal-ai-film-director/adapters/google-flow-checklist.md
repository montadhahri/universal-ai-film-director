# Google Flow / Veo — evidence-based adapter checklist

This checklist supplements [google-flow.md](google-flow.md); it does not
assert current Google Flow/Veo capabilities.

Before giving model-specific directions, identify the exact Flow interface,
selected Veo model/version, user's available controls and date. Verify:
- Allowed clip lengths, aspect ratios and export resolutions.
- Image/character reference inputs and continuity features.
- Native audio, dialogue, supported languages and audio limitations.
- Camera controls, editing, extension, scene/shot chaining if available.
- Account tier, quota, privacy and region restrictions where relevant.

Use Google's current official Flow/Veo help or product documentation and
record source URL/date in the capability matrix. If documentation is
unavailable, mark UNVERIFIED rather than supplying made-up button names.

Always provide **separate**:
1. Reference-image brief (only if supported).
2. Visual clip prompt for one shot.
3. Narration/dialogue cue and time range.
4. Music/SFX/editing/transition instructions.

If a requested shot exceeds verified clip limits, split into independently
reviewable shots. If native speech is unreliable or unverified, propose a
separate recorded narration track. Do not claim direct integration.
