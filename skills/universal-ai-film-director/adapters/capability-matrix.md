## Verification procedure

1. Identify exact provider, product, model/version, account tier, platform
   (web/API), region and date. Do not infer one from another.
2. Check current **official provider documentation** for limits, controls and
   supported input/output formats. Save the URL and retrieval date.
3. Mark each capability `DOCUMENTED`, `TESTED`, `UNVERIFIED` or
   `UNSUPPORTED`. `TESTED` requires an actual execution and recorded
   environment/result, not a plausible prompt.
4. If a capability is missing, use a portable fallback (split clips, separate
   voice track, edit transitions externally, provide reference images only
   when supported).
5. Recheck before producing model-specific UI instructions or cost estimates.

**Do not** interpret a general marketing claim as evidence of a particular
duration, button, reference mode, lip-sync ability or export setting.
