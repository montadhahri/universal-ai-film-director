# Generator and execution checklist

Identify the actual model/provider and access before claiming support. Verify duration limits, aspect ratios, allowed image references, motion controls, generation output form, audio, account requirements, restrictions, costs and retries from official documentation or observed tool metadata.

Every **shot packet** includes: shot ID/revision, global timing, approved visual continuity anchors, optional real image references, clip generation prompt, negative constraints, audio instructions as a separate section and edit/transition instructions.

Use execution evidence states: PLAN_ONLY, BLOCKED_NO_PROVIDER, REQUESTED, GENERATED, RETRIEVED, INSPECTED. A job being submitted is not a playable clip. Separate user authorizations for costs, asset upload, generation and publication. Report provider errors accurately; keep prior approved assets untouched.
