# Worked provider decision — generator availability (illustrative)

**User request:** "Generate all five approved shots in Google Flow with synced narration."

**Step 1: verify authorization.** Is a supported Flow/Veo tool actually available to this agent? Has the user separately allowed account use, reference uploads, potential credits and generation jobs? An installable filmmaking skill does not answer these questions.

**Step 2: verify capabilities.** Capture provider, exact model/version, interface, check date, official source, tested clip length, aspect ratio, reference controls, native audio and downloadable file formats. Mark each `DOCUMENTED`, `TESTED`, `UNVERIFIED` or `UNSUPPORTED`. Do not invent button names.

**Step 3: prepare a shot packet.** Example for S01_SH02 (5–10 seconds): a child holds an amber spark; close-up, gentle push, consistent clothing and dark skyline, illumination strictly from the spark. Keep actual reference image instructions separate from visual clip prompt, English narration cue, sound and edit instructions.

**Step 4: if no tool exists.** Return `BLOCKED_NO_PROVIDER` for actual execution and provide copy-ready packets. Do not claim generated clips, usage of credits, approval or exported MP4. Suggest a separate narration track if native VO support is unverified.

**Step 5: if an authorized tool exists.** Record actual job identifiers and observed results; retrieval is not inspection, and a submitted job is not a rendered clip. Respect per-shot rollback and unchanged locked neighbors.
